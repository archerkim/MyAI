# Research branch: temporal + updatable + vector-recall memory

Цель ветки — превратить символический граф знаний из статической **базы знаний** в
полноценную **агентную память**, конкурентную с Zep/Graphiti и Mem0 по трём осям,
которых не хватало:

1. **Темпоральность** — знание меняется во времени.
2. **Update-семантика** — забыть / заменить / разрешить конфликт.
3. **Векторный recall** — поиск по смыслу, а не по точному имени.

Логический слой (FOL: вывод, противоречия, proof-trees) и проверяемость
(«отвечай по рёбрам или откажись») у системы уже есть — и в этом она опережает
большинство решений памяти. Эта ветка добивает недостающее.

## Что добавлено

| Модуль | Что даёт | Аналог у лидеров |
|---|---|---|
| `temporal_memory.py` | би-темпоральные факты (valid_from/valid_to + recorded_at), `current(at)`-срез, `assert/update/invalidate`, корроборация по confidence | Zep/Graphiti (би-темпоральность) |
| `vector_recall.py` | семантический recall концептов через `nomic-embed-text` | hybrid-retrieval в Mem0/GraphRAG |

## Как встраивается в существующую систему

```
ЗАПИСЬ:   extractor → TemporalStore.assert/update  (вместо прямой укладки)
                              │  current(at=now)
                              ▼
                      граф C-ядра (актуальный срез)  →  reasoner (FOL) / talk
ЧТЕНИЕ:   вопрос → vector_recall.search ∪ lexical anchors → окрестность → qwen
```

- **Запись через TemporalStore**: ингест больше не «дописывает» факты, а
  *утверждает* их с временем. Функциональные отношения (`located_in`,
  `defined_as`, …) обновляются (старое значение закрывается). `current()` даёт
  актуальный срез, который материализуется в `.brain` для рассуждения.
- **Чтение с векторным recall**: якоря `talk.py` дополняются семантически
  близкими концептами (`«rubbing surfaces» → friction`), что чинит провал recall
  на перефразах.

## Проверено
- «Переезд»: `located_in paris [t1..t2]`, `london [t2..]`; `current(at)` отдаёт
  верный город на момент времени.
- Корроборация: повтор факта копит confidence.
- Forget: `invalidate` убирает из актуального, сохраняя историю.
- Векторный recall на графе механики: `rubbing surfaces → friction`,
  `push or pull → force`, `heat and light → heat/illuminate`.
- 50 unit-тестов (8 новых) зелёные.

## Открытые задачи (направление дальше)
1. **Политика разрешения конфликтов**: при противоречии (`find_contradictions`)
   выбирать по confidence/времени/источнику, а не только детектировать.
2. **Темпоральный FOL**: правила вывода с учётом времени (валидность следствия
   ограничена валидностью посылок).
3. **Гибридный ранкер чтения**: объединять vector + spreading-activation +
   conductance в одну оценку релевантности.
4. **Масштаб**: вынести граф из .brain-файлов в БД (тот же SQLite/нативный
   индекс), батч-эмбеддинги, ANN-индекс для recall.
5. **Источник истины**: сделать TemporalStore первичным хранилищем, а `.brain` —
   производным актуальным срезом (rebuild from current()).
